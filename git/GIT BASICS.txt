TYPES OF REPOSITORY

THEY ARE TWO TYPES OF REPOSITORY 1)CENTRAL 2)LOCAL

*****CENTRAL REPOSITORY-- IS LOCATED IN REMOTE SERVER WHERE ALL THE PROJECT RELATED FILES ARE STORED AND ALL THE MEMEBERS OF THE PROJECT CAN ACCESS THE CENTRAL REPOSITORY BY THE CODE. THE MAIN THING TO ACCESS THE CENTRAL REPOSITORY IS TO IF ANY ONE HAVING THE DOUBTS CAN ACCESS IT. .GIT FOLDER IS PRESENT IN CENTRAL REPOSITORY ALL THE DEVLOPERS CAN SHARE AND EXCHANGE DATA. THE PROJECT DONE BY THE MEMEBER IN A TEAM CAN PUSH THE FOLDER TO THE CENTRAL REPOSITORY SO THAT EVERYONE CAN SEE THE PROJECT PROGRESS.


LOCAL REPOSITORY- EVERYONE USES THE LOCAL REPOSITORY BUT IT IS USED INDIVIDUALY. AND WHEN THE WORK IS DONE IN THE LOCLA REPOSTORY BY THE FELLOW MEMBER IT CAN BE PUSHED TO CENTRAL REPOSITORY WHERE ALL CAN ACCESS IT.
